# 日镜账

中文名：**日镜账** · 前缀 `daysnap` · 端口 **6600 / 11600**

## 骨架

**日终余额抽取 → 周期快照落行 → 变动流水回放核对 → 断档/跳变检出 → 快照与回放差额清单**

皮：收单/结算账户的日终余额镜。去皮是 **周期快照事实 + 流水回放守恒 + 断档跳变检出**，不是银行核心 CRUD、不是日结封账锁定、不是双边齐账。

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 账户册 | 参与日终抽取的账户 |
| 变动流水 | 按营业日增减额 |
| 周期快照 | 账户×营业日余额镜 |
| 回放核对 | 前日快照+当日流水 vs 当日快照 |
| 差额清单 | 不一致行 |
| 断档/跳变 | 缺前日镜、偏离阈值 |
| 旁置簿 | 未入账载荷 |
| 销户终镜 | 销户同票落终态有效镜并冻结正式写（口径：善后旁置轨） |
| 善后旁置簿 | 销户后迟到装载的善后轨，不进正式净额、不改终镜 |

## 销户终镜（口径乙 · 善后旁置轨）

* 销户须**同票**完成：账户状态字→已销户 + 终态有效镜（`销户终镜` 凭证），缺销户日有效快照则失败闭，禁止只改状态字。
* 销户后迟到装载：不进正式 `变动流水`/净额、不改终镜，落 `善后旁置簿`（装载返回 `善后旁置` 计数，`入账=0`）。
* 销户日再抽取（含后续日）：写闸硬拒（HTTP 400），整票回滚，终镜永不被盖写。
* 核证接口 `GET /api/销户终镜/核证/{account}`：`终态余额 / 可写 / 善后 / valid`。
* 善后须另票：`POST /api/善后结清/{account}` 结清善后轨 → `POST /api/解销` 作废旧镜并恢复正式写；善后未结清不得解销，善后禁止潜入正式有效镜。
* 与口径甲（双路径皆拒）的可区分断言：销户后再装一笔，**善后旁置非空且终镜余额不变、正式净额不偷变**。
